# 参与贡献（CONTRIBUTING）

感谢你考虑为本技能群做贡献。本文件说明协作约定，请先读完再动手。

## 本项目是什么

一个 ACMG/AMP 单病变异评级技能群（调度层 + 收尾层 + 证据码子技能 + 确定性组合引擎）。定位：**辅助人工评级的合规引擎**，结论由人工定级。

## 如何参与

- **报告问题 / 提需求**：GitHub Issues；
- **改证据码子技能 / 调度 / 收尾 / 引擎**：见下方硬性规范，改前先建 Issue 说明动机；
- **补文档 / 修工程骨架**：欢迎 PR。

## 硬性开发规范（必须遵守）

1. **版本留痕**：改动任何子技能正文，必须**同步升 frontmatter 版本号 + 记入该技能 CHANGELOG**；引擎脚本改动须更新文件头版本号并留痕。
2. **互斥信息只在收尾**：证据码之间的互斥关系**只允许存在于收尾技能 `acmg-conflict-summary-output` 的互斥矩阵**；各 `ev-*` 证据码子技能**严禁携带任何互斥内容**（互斥是证据码间关系，与单码评定无关）。
3. **不引入外部锚点之外的内容**：证据判定一律按指南/权威源（ClinGen VCEP、权威文献）口径，通用=通用、特异=特异，先查数据后匹配，不引入新问题。
4. **确定性优先**：能固化为确定性脚本/流程的，不要靠 LLM 文字自由裁定；输出须可复现、可溯源。

## 验证原则（重要）

- **不做需人工标注的验证**（kappa / 独立回测）；所有测试优先做**自动化**部分（门禁、回归、契约测试、故障注入等）。
- 需要人工专家判定的验证，**等待开源后由社区自发完成**，不在维护侧依赖人工标注。
- 对外口径：只称"双引擎自洽率"，**不称"准确率"**（尚无 hold-out 权威基准，结论由人工定级）。
