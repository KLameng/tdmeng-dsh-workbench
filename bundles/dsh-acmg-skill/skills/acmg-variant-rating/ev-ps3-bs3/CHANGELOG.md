## v1.7.0（PS3/BS3 VCEP 基因特异档位路由，2026-10-20）

- **新增 PS3/BS3 第 3.5 步 VCEP 基因特异档位路由协议**（与 ev-pm2 / ev-bs1-bs2 / ev-pp1 / ev-pp3-bp4 同源）：判定 PS3/BS3 前先判断该基因是否有 ClinGen VCEP cspec 且 PS3/BS3 段定义可路由的实验分档规则；有 → 路由读 `clingen-vcep/knowledge-base/VCEP-<gene>.md` 的 `#### PS3`（致病侧）/ `#### BS3`（良性侧）段原文，按原文档位判定，**优先于通用对照数目/OddsPath 表**；无 PS3/BS3 段/引用式无数值 → 回退通用表。
- **明确 PS3/BS3 与数值类码的本质差异（写死）**：核心是"功能实验类型 + 判据 → 档位"（语义判定，非数值切点）。同一基因 VCEP 定义可用实验类型（RNA/酶活/电生理/Kato/寡聚化/GTPase 等，无法穷举）与各档判据。判定必须按该基因 VCEP 原文识别实验类型 + 核验判据满足，不得套用其它基因实验类型或通用 OddsPath 档。
- **新增引擎 `acmg_evidence.py::ps3_vcep_band`**（spec 驱动确定性比较，PS3/BS3 双前缀）：支持 experiment 分档（每档多条判据 AND，判据含数值 op 与语义布尔/枚举）+ 判据缺失跳过低档 + reference_only 回退 + 封顶 + 前置排除。不硬编码基因，spec 由路由读原文传。
- **与通用表关系写死**：通用对照数目/OddsPath 表仅在"该基因无 VCEP PS3/BS3 特异规则"时使用；证据性质核验 + 穷尽检索仍为任何情形下前置硬步骤（VCEP 路由管"用哪个特异切点/实验判据定档"，核验与穷尽检索管"该功能实验是否真正支持本特异变异"，并行不冲突）。
- **契约测试**：`contract_test.py` 新增第 12 节 ps3_vcep_band 14 条用例（TP53 Kato 三档 / GAA 酶活数值 / CDH1 RNA / BS3 镜像 / 引用式/封顶/非法 spec），全 PASS，无回归（118 通过 / 0 失败）。
- **判例写死**：GAA 酶活分档——VCEP GAA PS3 酶活<5%→Moderate、<30%→Supporting（通用 OddsPath 无此切点）；测到残余酶活 10% → 按 VCEP 是 PS3_Supporting，不得因 OddsPath 通用表误判 Moderate/Strong。

## v1.6.0（残余酶活映射降级为示例性判例，2026-10-19 v20 审计 N4 处置）

- **根因（v20 审计 N4）**：v1.5.0 的"≤5%→Strong / 5–30%→Moderate / >30%→Supporting"被审计指出——**无出处**（5%/30% 阈值无 PMID/ClinGen 来源）、**阈值基因/方法依赖**（残余酶活百分比的分母/检测体系/底物各病差异大，跨基因统一表风险）、**引擎不可见**（PS3 档位由 LLM 层自由给，无门禁能发现误用）。
- **降级定位（v1.6.0，不伪造出处）**：明确为**示例性判例参考、非通用硬阈值、须按基因/方法逐案核**——不得套作跨基因统一阈值表；实际评级以「对照数目/OddsPath」维度与实验质量为准定档；并如实声明"引擎不感知酶活数据、本表为判例指引非确定性门禁"（酶活数据在技能层，引擎拿不到，不强造门禁）。
- **保留（不引入新问题）**：原有叠加纪律全部保留并补"阈值逐案核"项（限酶活类/须针对本变异/须阳阴性对照/无充分对照单篇生化仍最高 Supporting/不以残余酶活单点升档）；只降级定位，不删除判例参考价值。
- **版本**：**1.5.0→1.6.0**；引擎未动。

## v1.5.0（残余酶活维度参考映射，2026-10-16 用户复盘"PS3 强度给低"）

- **根因**：评级实证——成纤维细胞酶活 0-5%（四家独立实验室、金标准方法、严重功能受损）只给 PS3_Supporting，应为 Strong；ev-ps3 无"残余酶活百分比→档位"映射。
- **新增「残余酶活维度参考映射」**（在 OddsPath 表后）：≤5%（几乎无功能）→PS3_Strong、5–30%（部分功能）→PS3_Moderate、>30%（轻度受损）→PS3_Supporting。
- **防引入新问题（写死边界）**：只适用「酶活/功能活性类实验」（酶病/代谢病基因），不套剪接/RNA/转运/信号通路；是残余活性**单一维度判例参考**，与「对照数目/OddsPath」维度**叠加**共同定档、不替代；还需实验针对本特异变异 + 有阳/阴性对照（无充分对照单篇生化仍最高 PS3_Supporting，不被本映射顶到 Strong）+ 方法已广泛验证（金标准）。自检清单补核对项。
- 纯流程/契约层改动，不改引擎。
