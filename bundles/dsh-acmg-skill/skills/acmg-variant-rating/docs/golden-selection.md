# 金标准选样标准（golden-selection.md）

> 说明金标准（golden.json）如何选样、录入、维护。金标准是**评测输入快照、基准，不是被测对象**。

## 一、来源优先级（只取权威，禁止自编）

1. **ClinGen VCEP 已定级位点**（最高权威，通常公开证据码）；
2. **ClinVar Expert Panel / 多星（≥2 星）评级位点**；
3. **已发表、多中心达成共识的位点**；
4. 经用户确认为权威口径的人工答案（仅当 1-3 不可得，且须注明）。

> 铁律：金标准不得来自技能群自己评出的结果；不得用技能 SKILL 内"案例/举例"位点当金标准。

## 二、规模与覆盖（强制）

- **规模 ≥ 40 个独立变异**（独立 = 非同基因同一位点重复）；
- **四象限覆盖**：P / LP / VUS / B·LB 各象限都要有，不得只测致病侧；
- **四类型覆盖**：错义 / 截短（无义·移码）/ 剪接（±1,2·深内含子）/ 框内 indel，每型都要有。

## 三、录入字段（每个位点）

`变异HGVS | 基因 | 权威分类 | 权威证据码(如有) | 来源(VCEP/ClinVar/共识/人工)`

逐码对比时，权威证据码作为"应使用的码"基准。

## 四、维护与冻结

- **现役 golden.json 冻结不动**：它是评测输入快照（基准），升级过程**绝不动现役 golden**；
- 口径变更（如争议证据码处理）**不改现役**，需**新冻一版并重建评测**，而非就地改；
- 外部权威（ClinGen VCEP / cspec）升版 → 触发金标准扩充评估（新增位点），扩充的是"检验覆盖"，不改变"评价对象=技能群"。

## 五、两集分离（回归 / 盲测）

- **回归集**：常规迭代快速回归用；
- **盲测集**：上线验收用（四象限完整），**盲测保密，不进发布包**（`tests/blind/` 仅占位）。
