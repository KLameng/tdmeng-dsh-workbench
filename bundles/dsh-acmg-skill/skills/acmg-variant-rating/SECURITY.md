# 安全与隐私（SECURITY）

## 项目定位

本技能群是**辅助人工评级的合规引擎**：只负责按 ACMG/ClinGen 指南把评级流程严格走一遍，**最终结论由人工定级**。技能群输出合规证据流程 + 提示池，不替代临床决策。

## 数据与隐私边界（重要）

- **评级归档含单变异位点评级结论**，属敏感数据。按本项目合规边界：**归档数据不上公开代码库**，由 `.gitignore` 排除（`acmg_result_archive.json` / `*.archive.json`），仅存于受控存储。
- 涉及个人可识别信息（样本号、受检者信息等）的字段，**必须脱敏**后方可进入任何可追溯记录。
- 跨设备云盘归档同步（`lark-cli`）遵循"失败不阻断评级"边界：同步失败记 warning、评级继续，不因工具不可达而静默吞错。

## 依赖安全

- `requests`：NCBI E-utilities 等请求的 HTTP 库，建议设置真实 `NCBI_EMAIL` 规避限流；
- `pyliftover`：hg19↔hg38 坐标转换核心依赖，版本漂移直接影响坐标结果，建议锁定实测版本；
- 涉及 gnomAD 的查询默认**严格校验 SSL 证书**，不设降级（`GNOMAD_INSECURE` 仅在证书确属错位时临时使用）。

## 报告安全/合规问题

- 公开问题：在本仓库 GitHub Issues 提交（说明影响面、是否含敏感数据）；
- 敏感问题（涉评级结论、隐私数据）：不公开提交，通过项目维护者的开源联系渠道私信，并注明"SECURITY 报告"。
