============================================================
  Td.蒙 · dsh 工作台　使用说明（给不写代码的你）
============================================================
  这是什么？
------------------------------------------------------------
  一个双击就能用的 AI 工作台。它自带一个网页聊天界面，
  里面住着：

    · 总管（chief-dispatcher）：负责听你说话、判断该找谁，
      自己不抢专家的活。
    · TACT 三轴坐标专家：给「AI 出错的现象」定位坐标
      （L 在哪一层犯 / M 怎么错的 / P 破坏了哪一面）。
    · ACMG 变异评级专家：给基因变异做致病性证据评级
      （PVS1/PS/PM/PP… 那一整套，共 22 个子技能）。

  你只管在网页里用大白话提问，总管会自动把活派给对的专家。
  这是【离线完整版】：运行环境已随包带齐，解压后不用再联网安装。


------------------------------------------------------------
  第一次使用：只要 2 步
------------------------------------------------------------
  第 1 步：启动

     双击  →  启动工作台.bat

     会弹出一个黑色窗口（这是发动机，用的时候别关它），
     随后浏览器会自动打开 "DeepSeek Harness" 网页。

  第 2 步：在网页里填一次模型 Key（只配这一次，以后都记住）

     在打开的网页里：
       点「设置 / Settings」 →  选「模型 / Models」
       找到「火山方舟（豆包）」这一栏（路由名 volc-ark）
       在 API Key 输入框里粘贴你的火山方舟 Key，保存。

     （Key 在火山方舟控制台 → API Key 管理 里创建，以 sk- 开头。）
     保存即生效，不用重启、不用碰任何文件。
     想填多把 Key：同一栏填好火山的；以后若接别家大模型，
     在同一页面「添加服务商 / Add provider」再填即可，互不影响。

  回到对话：网页对话框旁边有一个【模型选择器】，点开就能选
  这一轮要用哪个大模型（预置了豆包 Seed 2.1 Pro）。
  在设置里加了几个模型，这里就能选几个，想用哪个点哪个。

  （习惯改文件的老用户：仍可双击「填写模型Key.bat」在
    home\.env 里填 VOLC_ARK_API_KEY 作为备用方式，界面里
    填的会优先于它。一般人用界面即可，不用管这个。）


------------------------------------------------------------
  怎么问（照着抄就行）
------------------------------------------------------------
  · AI 出错类（自动找 TACT 专家）：
      "帮我用三轴定位这个 AI 错误：模型把 α 地贫的 WS 位点
       说成了缺失型，现象是……"

  · 基因变异评级类（自动找 ACMG 专家）：
      "帮我评级：BRCA1，c.5266dupC，p.Gln1756Profs，
       常染色体显性，患者杂合。"

  · 拿不准归谁时，直接把整句话丢给总管，它会分诊；
    一件事同时涉及两边时，它会让两边各出各的结论，不混为一谈。


------------------------------------------------------------
  关闭与下次再用
------------------------------------------------------------
  · 关闭：把那个黑色窗口直接关掉，服务就停了。
  · 下次：再双击「启动工作台.bat」即可，Key 已记住，不用重填。


------------------------------------------------------------
  ACMG 专家的一个一次性小前提（只用 ACMG 时才需要）
------------------------------------------------------------
  ACMG 取基因数据要用到 Python 的两个小模块（requests、
  pyliftover）。大多数电脑第一次没有，症状是它会提示取数失败。
  最简单的确认方式：在网页里对总管说一句

      "跑一下 acmg_env_check 环境自检"

  它会告诉你 Python 和这两个模块齐不齐、缺哪个、怎么补。
  需要补时，让懂一点点电脑的同事在命令行执行一次：

      python -m pip install requests pyliftover

  TACT 专家不依赖 Python，不受此影响。


------------------------------------------------------------
  常见小问题
------------------------------------------------------------
  Q：双击启动后，浏览器没自动打开？
  A：看黑色窗口里有一行类似
       dsh web: http://127.0.0.1:3080/?token=xxxx
     把这一整行（带 ?token= 那一长串）复制，粘贴到浏览器
     地址栏回车即可。

  Q：提示"端口已被占用 / 工作台很可能已经在运行"？
  A：说明之前已经启动过一个。直接看已经打开的网页即可；
     若想重启，先把旧的黑色窗口全部关掉，再双击启动。

  Q：黑窗口里一串红色/英文，是不是坏了？
  A：只要网页能打开、能正常对话就不影响使用。真启动失败时
     窗口会停住并写明原因，把那段文字发给出品方即可。

  Q：我的 Key 会不会被传出去？
  A：不会。在界面「设置」里填的 Key，只加密保存在本文件夹
     home\\.credentials.yaml 里（用文件方式填的则在 home\\.env）；
     整个工作台在你自己电脑上运行，不经过第三方服务器转发
     （模型请求按火山方舟官方接口直连）。换电脑/分享时，
     不要把 home 文件夹连同 Key 一起给人即可。

  Q：换了 Key 或提示 Key 无效怎么办？
  A：回「设置 → 模型 → 火山方舟」，把新 Key 重新粘贴保存即可，
     下一次提问立即生效，无需重启。


------------------------------------------------------------
  文件夹都是干嘛的（一般不用动）
------------------------------------------------------------
    node\\            自带的运行环境（免安装）
    node_modules\\    工作台引擎（已装好，勿删）
    bundles\\         两位专家的技能包
    dispatcher\\      总管的调度说明书
    home\\            你在界面填的 Key(.credentials.yaml) 与本机使用记录
    config\\          每次启动自动生成，可不管
    start.js          启动逻辑
    启动工作台.bat     平时就点这个（先启动，再去网页设置里填 Key）
    填写模型Key.bat    备用：习惯改文件的人才用（界面填 Key 优先）
    首次安装依赖.bat   一般用不到（离线版已含依赖；备用）
